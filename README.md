# Homologador CALLMED

Programa web para homologar descripciones de servicios médicos contra el catálogo maestro CALLMED.

Abre la página publicada. La IA funciona a través de una función de Supabase (`groq-proxy`): no hace falta
pegar ninguna llave. Quien quiera usar su propia llave de Groq puede pegarla en el panel "IA" del paso 3.
